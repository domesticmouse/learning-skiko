Parsimony Pressure & Style Constraints

Combat genetic bloat, balance fidelity against stroke economy via Pareto optimization, and guide evolutionary algorithms toward distinct artistic styles.

1 The Problem of Genetic Bloat

If an evolutionary algorithm is permitted to add strokes unconstrained, it will inevitably succumb to genetic bloat (overfitting):

  • The chromosome expands to thousands of tiny, microscopic stroke splatters.
  • Each stroke merely adjusts 3 or 4 pixels by 0.5% opacity, contributing virtually zero aesthetic value.
  • Rendering times explode from 0.1 ms to 15 ms per frame, suffocating evolutionary throughput.
  • The resulting vector painting resembles a noisy photographic raster rather than an intentional work of human art.

In traditional fine art, master painters achieve beauty through economy of means: conveying the full emotional essence of a subject with the fewest, most decisive brush marks possible.

2 Formulating Parsimony Penalties

In evolutionary computation, parsimony pressure introduces an explicit cost for chromosome complexity. Rather than optimizing pixel error alone, our objective function penalizes stroke quantity, ink volume, or total path length:

\[ F_{regularized}(P) = E_{pixel}(P, T) + \alpha \cdot N_{strokes} + \beta \cdot \sum_{i=1}^{N_{strokes}} \text{Area}(S_i) \]

Where:

  • \(E_{pixel}(P, T)\) is the perceptual CIELAB or SSD difference between painting \(P\) and target \(T\).
  • \(\alpha > 0\) is the parsimony multiplier per stroke. A mutant that adds a stroke must reduce pixel error by at least \(\alpha\) to survive selection.
  • \(\beta \ge 0\) is an optional penalty on stroke surface area or path curvature, discouraging visual noise.

3 The Pareto Optimality Frontier

Genetic art is fundamentally a multi-objective optimization problem. There is no single "perfect" solution, but rather a set of non-dominated solutions forming a Pareto Frontier:

\[ P_A \succ P_B \iff \big(E(P_A) \le E(P_B) \land N(P_A) \le N(P_B)\big) \land \big(E(P_A) < E(P_B) \lor N(P_A) < N(P_B)\big) \]

A 25-stroke painting with 15% error and a 150-stroke painting with 6% error are both Pareto-optimal: each is the best possible representation at its respective level of abstraction.

4 Artistic Style Constraints

By calibrating parsimony hyperparameters and mutation constraints, you can guide the evolutionary engine into radically different aesthetic movements:

🎨 Impressionist (Monet / Cézanne)

Enforce large minimum stroke widths (\(w \ge 12\text{px}\)), restrict stroke budget to 80, and bias stroke angles along dominant image color gradients.

✒️ Minimalist Contour Art

High \(\alpha\) penalty, monochrome or two-tone palette, thin stroke widths, and heavy penalties on overlapping intersections to force clean, continuous contours.

🌪️ Directional Flow Field (Van Gogh)

Rotate stroke control points to align with a vector flow field derived from the target image's Sobel gradient tangents: \(\theta(x, y) = \arctan2(-G_x, G_y)\).

6 Regularized Evaluator in Kotlin

Incorporate parsimony pressure directly into your Kotlin fitness evaluation routine:

RegularizedEvaluator.kt 
class RegularizedEvaluator(
    val target: TargetImage,
    val baseEvaluator: Evaluator,
    val parsimonyAlpha: Double = 250.0,
    val maxStrokeBudget: Int = 100
) {
    fun evaluate(painting: Painting): Double {
        val strokeCount = painting.strokes.size

        // Hard constraint: disqualify chromosomes exceeding stroke limit
        if (strokeCount > maxStrokeBudget) {
            return Double.MAX_VALUE
        }

        // Base pixel difference
        val pixelSSD = baseEvaluator.evaluate(painting)

        // Linear parsimony penalty per stroke
        val penalty = strokeCount * parsimonyAlpha

        return pixelSSD + penalty
    }
}
