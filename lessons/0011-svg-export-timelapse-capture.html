SVG Vector Export & Time-Lapse Capture

Transform evolved chromosomes into infinitely scalable W3C SVG vector assets, implement deterministic checkpointing, and compile high-framerate evolution time-lapses via CLI.

1 The Power of Vector Scalability

Raster images (PNG, JPEG) are tied to fixed grid dimensions. If you evolve a painting on a \(256 \times 256\) pixel canvas and blow it up to a gallery poster, the raster dissolves into jagged, blurry blocks.

Because our chromosome representation consists purely of mathematical curves, we possess a superpower: resolution independence. The exact same 10 KB chromosome can render with pin-sharp clarity on a mobile screen, an 8K display, or a 10-meter vinyl billboard.

2 W3C SVG XML Serialization

The Scalable Vector Graphics (SVG) format is an open W3C standard based on XML. An SVG file contains a root <svg> element with coordinate boundary definitions:

Root SVG Structure
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 256 256" width="100%" height="100%">
  <rect width="100%" height="100%" fill="#0f111a"/>
  <!-- Vector stroke elements appended in paint layer order -->
</svg>

3 Translating Béziers to SVG Paths

In SVG path syntax, quadratic Bézier curves are drawn using the Q command:

\[ \texttt{d="M } x_1,y_1 \texttt{ Q } c_x,c_y \;\; x_2,y_2\texttt{"} \]

Cubic Bézier splines are drawn with the C command:

\[ \texttt{d="M } x_1,y_1 \texttt{ C } cx_1,cy_1 \;\; cx_2,cy_2 \;\; x_2,y_2\texttt{"} \]

Colors with alpha transparency are mapped directly to SVG attributes:

SVG Path Element
<path d="M 45.2,180.1 Q 128.0,40.5 210.8,180.1" 
      stroke="rgb(56, 189, 248)" 
      stroke-opacity="0.45" 
      stroke-width="14.5" 
      stroke-linecap="round" 
      fill="none"/>

4 SVG Export & Checkpoint Serialization (.gene)

Evolutionary runs can span millions of generations across multiple hours. Below, we implement both W3C SVG vector export and compact line-oriented .gene checkpoint serialization (save & resume) directly against our Phase 1 Painting and StrokeGene classes:

PaintingExport.kt 
import java.io.File
import java.util.Locale

fun Painting.toSvg(width: Int, height: Int): String = buildString {
    appendLine("""<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 $width $height">""")
    appendLine("""  <rect width="$width" height="$height" fill="#ffffff"/>""")
    for (stroke in strokes) {
        val opacity = String.format(Locale.US, "%.3f", stroke.a / 255f)
        appendLine(
            """  <path d="M ${stroke.x0},${stroke.y0} Q ${stroke.xc},${stroke.yc} ${stroke.x1},${stroke.y1}" """ +
            """stroke="rgb(${stroke.r},${stroke.g},${stroke.b})" stroke-opacity="$opacity" """ +
            """stroke-width="${stroke.strokeWidth}" stroke-linecap="round" fill="none"/>"""
        )
    }
    appendLine("</svg>")
}

/**
 * Writes the current Painting chromosome to a human-readable .gene checkpoint file
 * so long evolutionary runs can be paused and resumed without losing progress.
 */
fun Painting.saveCheckpoint(file: File) {
    file.bufferedWriter().use { out ->
        out.appendLine("# GENETIC_ART_V1 error=$error strokes=${strokes.size}")
        for (s in strokes) {
            out.appendLine("${s.x0},${s.y0},${s.xc},${s.yc},${s.x1},${s.y1},${s.strokeWidth},${s.r},${s.g},${s.b},${s.a}")
        }
    }
}

fun loadCheckpoint(file: File): Painting {
    val lines = file.readLines()
    val header = lines.firstOrNull { it.startsWith("# GENETIC_ART_V1") } ?: ""
    val savedError = header.substringAfter("error=", "").substringBefore(" ").toLongOrNull() ?: Long.MAX_VALUE

    val strokes = lines.asSequence()
        .filter { it.isNotBlank() && !it.startsWith("#") }
        .map { line ->
            val p = line.split(",")
            StrokeGene(
                x0 = p[0].toFloat(), y0 = p[1].toFloat(),
                xc = p[2].toFloat(), yc = p[3].toFloat(),
                x1 = p[4].toFloat(), y1 = p[5].toFloat(),
                strokeWidth = p[6].toFloat(),
                r = p[7].toInt(), g = p[8].toInt(), b = p[9].toInt(), a = p[10].toInt()
            )
        }
        .toList()

    return Painting(strokes = strokes, error = savedError)
}

5 Automated Frame-Dump Time-Lapses

Watching an artwork assemble itself stroke by stroke is mesmerizing. However, saving a PNG on every accepted mutation would generate 50,000 files and exhaust disk I/O.

Instead, capture frames along a logarithmic or geometric cadence:

Early Phase (Rapid Form)

Dump a frame every 10 accepted mutations during generations 0 to 1,000 to catch broad brush placement in high temporal resolution.

Late Phase (Micro Tuning)

Dump a frame every 250 accepted mutations during generations 10,000+ so fine detail refinement progresses at a smooth, visible playback pace.

6 Compiling 4K Videos via FFmpeg CLI

From the command line, combine your captured frames into a silky-smooth 60 FPS video using ffmpeg:

Terminal (CLI) 
# Assemble PNG sequence into high-quality 4K H.264 video
ffmpeg -framerate 60 -i frames/frame_%05d.png \
       -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p \
       evolution_timelapse.mp4

8 Automated Testing for SVG & Checkpointing

Reliable production export demands automated unit tests. We verify that toSvg() generates well-formed W3C XML containing coordinate viewboxes and curve commands, and that saveCheckpoint() and loadCheckpoint() achieve lossless round-trip serialization:

src/test/kotlin/PaintingExportTest.kt 
import java.io.File
import kotlin.test.Test
import kotlin.test.assertEquals
import kotlin.test.assertTrue

class PaintingExportTest {
    @Test
    fun testToSvgGeneratesValidXml() {
        val strokes = listOf(
            StrokeGene(10f, 20f, 30f, 40f, 50f, 60f, 4.5f, 255, 128, 0, 200),
            StrokeGene(5f, 15f, 25f, 35f, 45f, 55f, 2.0f, 0, 255, 128, 100)
        )
        val painting = Painting(strokes = strokes, error = 123456L)

        val svg = painting.toSvg(256, 256)

        assertTrue(svg.startsWith("<svg xmlns=\"http://www.w3.org/2000/svg\""))
        assertTrue(svg.contains("viewBox=\"0 0 256 256\""))
        assertTrue(svg.contains("<rect width=\"256\" height=\"256\" fill=\"#ffffff\"/>"))
        assertTrue(svg.contains("d=\"M 10.0,20.0 Q 30.0,40.0 50.0,60.0\""))
        assertTrue(svg.contains("stroke=\"rgb(255,128,0)\""))
        assertTrue(svg.contains("stroke-width=\"4.5\""))
        assertTrue(svg.trimEnd().endsWith("</svg>"))
    }

    @Test
    fun testCheckpointSaveAndLoadRoundtrip() {
        val strokes = listOf(
            StrokeGene(12.5f, 34.2f, 56.1f, 78.9f, 90.0f, 12.3f, 6.5f, 250, 100, 50, 180),
            StrokeGene(1.0f, 2.0f, 3.0f, 4.0f, 5.0f, 6.0f, 1.5f, 10, 20, 30, 40)
        )
        val original = Painting(strokes = strokes, error = 987654321L)

        val tempFile = File.createTempFile("checkpoint_test", ".gene")
        try {
            original.saveCheckpoint(tempFile)
            assertTrue(tempFile.exists() && tempFile.length() > 0)

            val loaded = loadCheckpoint(tempFile)
            assertEquals(original.error, loaded.error)
            assertEquals(original.strokes.size, loaded.strokes.size)

            for (i in original.strokes.indices) {
                val s1 = original.strokes[i]
                val s2 = loaded.strokes[i]
                assertEquals(s1.x0, s2.x0)
                assertEquals(s1.y0, s2.y0)
                assertEquals(s1.xc, s2.xc)
                assertEquals(s1.yc, s2.yc)
                assertEquals(s1.x1, s2.x1)
                assertEquals(s1.y1, s2.y1)
                assertEquals(s1.strokeWidth, s2.strokeWidth)
                assertEquals(s1.r, s2.r)
                assertEquals(s1.g, s2.g)
                assertEquals(s1.b, s2.b)
                assertEquals(s1.a, s2.a)
            }
        } finally {
            tempFile.delete()
        }
    }
}

Run the export test suite using Gradle CLI:

Terminal
./gradlew test --tests "PaintingExportTest"

Why is SVG format mathematically superior to PNG for printing physical wall art?
SVG renders faster than hardware bitmaps.
SVG supports transparent alpha blending channels.
Vector paths preserve infinite physical resolution.
SVG compresses GPU memory video textures.
