1 Dual-Pane Side-by-Side Presentation

In Main.kt, the SkikoRenderDelegate.onRender() method draws two primary viewports:

  • Left Viewport: The immutable target image, rendered via canvas.drawImageRect(target.image, targetRect).

2 Designing the In-Canvas Skia HUD

Rather than using standard Swing UI buttons which clash with hardware-accelerated canvases, the entire dashboard and telemetry panel is drawn directly in Skia using RRect (rounded rectangles) and Skia Font:

HUD Rendering in Main.kt 
// Draw Rounded HUD Card
val hudRect = Rect.makeXYWH(32f, hudY, w - 64f, 82f)
canvas.drawRRect(RRect.makeXYWH(32f, hudY, w - 64f, 82f, 10f), cardPaint)
canvas.drawRRect(RRect.makeXYWH(32f, hudY, w - 64f, 82f, 10f), borderPaint)

3 Interactive Keyboard Controls

By attaching a standard AWT KeyAdapter to the JFrame, the user can adjust simulation parameters without restarting the application:

[SPACE] Pause / Resume

Toggles painter.togglePause(), freezing the background worker loop so you can inspect the current painting.

[R] Reset

Re-randomizes the entire chromosome back to generation 0, letting you restart evolution from a new seed.

[+] / [-] Adjust Stroke Count

Adds or removes 10 strokes dynamically, observing how chromosome complexity impacts visual fidelity.

[S] Save PNG

Encodes the current champion painting to a high-resolution lossless PNG file in the workspace directory.

4 Encoding & Saving Lossless PNGs

Skia includes native encoders for PNG, JPEG, and WebP. In Main.kt, exporting the painting requires only 4 lines of code:

Exporting PNG with Skia 
val saveBitmap = Bitmap().apply { allocN32Pixels(target.width, target.height) }
val saveCanvas = Canvas(saveBitmap)
currentChampion.render(saveCanvas, target.width.toFloat(), target.height.toFloat(), paint, path)

val saveImage = Image.makeFromBitmap(saveBitmap)
val data = saveImage.encodeToData(EncodedImageFormat.PNG)
if (data != null) {
    File("evolved-painting.png").writeBytes(data.bytes)
    println("Saved painting to evolved-painting.png")
}

5 Running from the Command Line

Because your environment is completely configured for command-line development, you can execute the app and pass custom target images directly:

Terminal (CLI Run Commands) 
# Run with procedural geometric fallback target:
./gradlew run

# Run with your own target image file:
./gradlew run --args="path/to/my-portrait.png"

# Verify code formatting:
./gradlew ktlintCheck
