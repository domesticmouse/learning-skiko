3 Interactive Keyboard Controls

By attaching a standard AWT KeyAdapter to the JFrame, the user can adjust simulation parameters without restarting the application:

[SPACE] Pause / Resume

Toggles painter.togglePause(), freezing the background worker loop so you can inspect the current painting.

[R] Reset

Re-randomizes the entire chromosome back to generation 0, letting you restart evolution from a new seed.

[+] / [-] Adjust Stroke Count

Adds or removes 10 strokes dynamically, observing how chromosome complexity impacts visual fidelity.

[S] Save PNG

Encodes the current champion painting to a high-resolution lossless PNG file in the workspace directory.

⚠️ Thread-Confinement Rule for Skia Bitmaps

Notice that in Main.kt, the UI render delegate allocates its own displayBitmap and displayCanvas (and key [S] allocates a dedicated saveBitmap) rather than sharing the worker thread's Evaluator buffers. Because Skia's Bitmap, Canvas, Paint, and Path are stateful and not thread-safe, every thread must own its own isolated rendering buffers—a critical rule we will rely on when scaling to multi-core worker pools in Lesson 6.

4 Encoding & Saving Lossless PNGs

Skia includes native encoders for PNG, JPEG, and WebP. In Main.kt, exporting the painting requires only 4 lines of code:

Exporting PNG with Skia 
val saveBitmap = Bitmap().apply { allocN32Pixels(target.width, target.height) }
val saveCanvas = Canvas(saveBitmap)
currentChampion.render(saveCanvas, target.width.toFloat(), target.height.toFloat(), paint, path)

val saveImage = Image.makeFromBitmap(saveBitmap)
val data = saveImage.encodeToData(EncodedImageFormat.PNG)
if (data != null) {
    File("evolved-painting.png").writeBytes(data.bytes)
    println("Saved painting to evolved-painting.png")
}

6 Automated Testing & Headless Verification

To ensure PNG export, HUD formatting, and dual-pane rendering operate reliably without manual GUI interaction, we verify snapshot binary magic headers and telemetry string representations:

src/test/kotlin/HudControlsTest.kt 
import org.jetbrains.skia.Bitmap
import org.jetbrains.skia.Canvas
import org.jetbrains.skia.EncodedImageFormat
import org.jetbrains.skia.Image
import org.jetbrains.skia.Paint
import org.jetbrains.skia.Path
import kotlin.test.Test
import kotlin.test.assertEquals
import kotlin.test.assertNotNull
import kotlin.test.assertTrue

class HudControlsTest {
    @Test
    fun testPngSnapshotEncoding() {
        val width = 128
        val height = 128
        val target = TargetImage.loadOrGenerate(null, width, height)
        val painter = GeneticPainter(target = target, initialStrokeCount = 20)
        val best = painter.getBestPainting()

        val bitmap = Bitmap().apply { allocN32Pixels(width, height) }
        val canvas = Canvas(bitmap)
        best.render(canvas, width.toFloat(), height.toFloat(), Paint(), Path())

        val image = Image.makeFromBitmap(bitmap)
        val pngData = image.encodeToData(EncodedImageFormat.PNG)

        assertNotNull(pngData, "PNG data should not be null")
        assertTrue(pngData.bytes.size > 8, "PNG file should contain data")

        // Validate PNG magic bytes: 0x89 0x50 0x4E 0x47
        val bytes = pngData.bytes
        assertEquals(0x89.toByte(), bytes[0])
        assertEquals('P'.code.toByte(), bytes[1])
        assertEquals('N'.code.toByte(), bytes[2])
        assertEquals('G'.code.toByte(), bytes[3])
    }

    @Test
    fun testHudMetricsStringFormatting() {
        val target = TargetImage.loadOrGenerate(null, 64, 64)
        val painter = GeneticPainter(target = target, initialStrokeCount = 40)

        painter.generations.set(12345)
        painter.acceptedMutations.set(890)
        painter.currentEvalsPerSec.set(1500)

        val hudString =
            "GEN: ${painter.generations.get()} | ACC: ${painter.acceptedMutations.get()} | EPS: ${painter.currentEvalsPerSec.get()}"
        assertEquals("GEN: 12345 | ACC: 890 | EPS: 1500", hudString)
    }
}
