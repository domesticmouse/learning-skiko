Adaptive Annealing & Multi-Resolution Pyramids

Accelerate convergence by dynamically scaling mutation variances through thermodynamic annealing and coarse-to-fine multi-resolution image pyramids.

1 The Exploration vs Exploitation Dilemma

In our foundational hill climber, mutation step sizes (e.g., jittering control points by \(\pm 20\) pixels) were hardcoded constants. This creates a severe fundamental tension:

🔭 Early Stage (Macro Blocking)

When starting from a blank canvas, large geometric shifts (jumping across half the canvas) are required to block in major compositional shapes and dominant background palettes.

🔬 Late Stage (Micro Refinement)

After 50,000 generations, a \(\pm 20\)-pixel leap will almost certainly ruin a refined contour, causing candidate acceptance rates to plummet below \(0.01\%\). Only sub-pixel micro-nudges have a chance of succeeding.

Static mutation step sizes waste millions of CPU cycles testing wild mutations that cannot possibly improve a mature painting. To maintain high acceptance velocity throughout the run, we introduce dynamic step-size annealing.

2 Temperature & Annealing Schedules

Inspired by metallurgy—where molten metal cools slowly so crystalline structures settle into minimal-energy configurations—we define a system temperature \(T(t) \in (0, 1]\) that decays over generation count \(t\).

An exponential cooling schedule dampens the coordinate mutation variance \(\sigma(t)\):

\[ \sigma(t) = \sigma_{min} + (\sigma_{0} - \sigma_{min}) \cdot \exp\left(-\frac{t}{\tau}\right) \]

Where \(\sigma_{0}\) is the initial wide search radius (e.g. 80 px), \(\sigma_{min}\) is the asymptotic micro-refinement floor (e.g. 1.5 px), and \(\tau\) is the decay time constant controlling cooling duration.

💡 Terminology Note: Step-Size Annealing vs. Metropolis Simulated Annealing

In optimization literature, the phrase annealing appears in two distinct mechanisms:

  • Step-Size Annealing (Mutation Cooling): Gradually shrinking the mutation radius \(\sigma(t)\) over time while still only accepting improvements (\(E_{\text{child}} \le E_{\text{parent}}\)).
  • Metropolis Simulated Annealing (Kirkpatrick et al., 1983): Occasionally accepting a worse candidate (\(\Delta E = E_{\text{child}} - E_{\text{parent}} > 0\)) with Boltzmann probability \(P = \exp(-\Delta E / T(t))\) to escape deep local minima.

In high-dimensional vector painting (where a 150-stroke genome has 1,650 continuous parameters), accepting worse strokes quickly degrades crisp edges. In practice, step-size annealing combined with Rechenberg's 1/5th rule (Section 3) and neutral drift (\(\le\)) delivers much cleaner visual convergence.

3 Rechenberg's 1/5th Success Rule

Rather than relying strictly on predetermined time decay, Hans-Paul Rechenberg proved mathematically that an evolutionary search converges at maximum theoretical velocity when approximately one out of every five mutations is accepted:

\[ \text{Acceptance Ratio } r_{acc} = \frac{N_{accepted}}{N_{evaluated}} \approx 0.20 \]

We measure \(r_{acc}\) over a rolling window of 1,000 generations and adapt \(\sigma\) dynamically:

\[ \sigma \leftarrow \begin{cases} \sigma \cdot 1.15 & \text{if } r_{acc} > 0.20 \quad \text{(landscape is smooth; explore wider)} \\ \sigma \cdot 0.85 & \text{if } r_{acc} < 0.20 \quad \text{(landscape is steep; narrow focus)} \end{cases} \]

4 Multi-Resolution Image Pyramids

Computing pixel differences across a high-resolution \(1024 \times 1024\) canvas requires comparing \(1,048,576\) pixels per generation. During the initial 5,000 generations, broad color blocking does not require high pixel fidelity.

By constructing a Gaussian Image Pyramid, we evolve coarse strokes on downsampled surfaces before progressively upscaling:

64×64
Level 2: Coarse 4,096 pixels (16x faster)
128×128
Level 1: Medium 16,384 pixels (4x faster)
256×256
Level 0: Full 65,536 pixels (Target detail)

When transitioning from Level 2 to Level 1, we multiply all coordinate genes by the upscaling factor \(2\times\). We can also freeze the initial foundation strokes so subsequent generations only introduce new fine-detail brushes.

6 Implementing the Annealing Scheduler & Pyramid Upscaler

Encapsulate annealing dynamics into a reusable Kotlin controller that combines exponential base cooling with Rechenberg's 1/5th adaptive gain, alongside a coordinate upscaler for transitioning between pyramid levels:

AnnealingSchedule.kt 
import kotlin.math.exp

class AnnealingSchedule(
    val initialSigma: Float = 60.0f,
    val minSigma: Float = 1.5f,
    val tau: Double = 15_000.0
) {
    private var rollingAccepted = 0
    private var rollingEvaluated = 0
    private var adaptiveGain: Float = 1.0f

    var currentSigma: Float = initialSigma
        private set

    fun getSigma(generation: Long): Float {
        // 1. Base exponential temperature decay
        val baseSigma = minSigma + (initialSigma - minSigma) * exp(-generation / tau).toFloat()

        // 2. Dynamic gain multiplier based on Rechenberg's 1/5th rule
        if (rollingEvaluated >= 500) {
            val ratio = rollingAccepted.toFloat() / rollingEvaluated
            if (ratio > 0.22f) {
                adaptiveGain = (adaptiveGain * 1.15f).coerceAtMost(2.5f)
            } else if (ratio < 0.18f) {
                adaptiveGain = (adaptiveGain * 0.85f).coerceAtLeast(0.25f)
            }
            rollingAccepted = 0
            rollingEvaluated = 0
        }

        // Combine scheduled cooling with live acceptance feedback
        currentSigma = (baseSigma * adaptiveGain).coerceIn(minSigma, initialSigma)
        return currentSigma
    }

    fun recordOutcome(accepted: Boolean) {
        rollingEvaluated++
        if (accepted) rollingAccepted++
    }
}

/**
 * Scales all stroke coordinates and widths when advancing up the Gaussian pyramid
 * (e.g., scale = 2.0f when promoting a champion from 64x64 -> 128x128).
 */
fun Painting.upscale(scale: Float): Painting = copy(
    strokes = strokes.map { s ->
        s.copy(
            x0 = s.x0 * scale, y0 = s.y0 * scale,
            xc = s.xc * scale, yc = s.yc * scale,
            x1 = s.x1 * scale, y1 = s.y1 * scale,
            strokeWidth = (s.strokeWidth * scale).coerceIn(2f, 40f)
        )
    },
    error = Long.MAX_VALUE // Force re-evaluation at the new pyramid resolution
)

7 Automated Testing & Verification

Testing adaptive cooling schedulers requires verifying exponential decay curves, gain adjustments from Rechenberg's 1/5th feedback rule, and vector chromosome coordinate upscaling:

src/test/kotlin/AnnealingScheduleTest.kt 
import kotlin.test.Test
import kotlin.test.assertEquals
import kotlin.test.assertTrue

class AnnealingScheduleTest {
    @Test
    fun testExponentialCoolingDecay() {
        val schedule = AnnealingSchedule(initialSigma = 50f, minSigma = 2f, tau = 10_000.0)

        val s0 = schedule.getSigma(0)
        assertEquals(50f, s0, 0.01f, "Sigma at gen 0 should equal initialSigma")

        val s10k = schedule.getSigma(10_000)
        assertTrue(s10k < s0, "Sigma must decrease over generations")

        val s50k = schedule.getSigma(50_000)
        assertTrue(s50k < s10k, "Sigma must continue cooling towards minSigma")
        assertTrue(s50k >= 2f, "Sigma must never cool below minSigma")
    }

    @Test
    fun testRechenbergSuccessRuleAdjustment() {
        val schedule = AnnealingSchedule(initialSigma = 40f, minSigma = 2f, tau = 100_000.0)

        // Simulate high acceptance rate (> 22%)
        repeat(500) { schedule.recordOutcome(accepted = true) }
        val boosted = schedule.getSigma(100)

        val freshSchedule = AnnealingSchedule(initialSigma = 40f, minSigma = 2f, tau = 100_000.0)
        // Simulate low acceptance rate (< 18%)
        repeat(500) { schedule.recordOutcome(accepted = false) }
        val contracted = schedule.getSigma(100)

        assertTrue(boosted >= contracted, "High acceptance should yield higher sigma than low acceptance")
    }

    @Test
    fun testPaintingUpscale() {
        val stroke =
            StrokeGene(
                x0 = 10f, y0 = 15f,
                xc = 20f, yc = 25f,
                x1 = 30f, y1 = 35f,
                strokeWidth = 4f,
                r = 100, g = 150, b = 200, a = 120,
            )
        val painting = Painting(strokes = listOf(stroke), error = 5000L)
        val upscaled = painting.upscale(2.0f)

        assertEquals(Long.MAX_VALUE, upscaled.error, "Upscaling must invalidate previous error score")
        val s = upscaled.strokes.first()
        assertEquals(20f, s.x0)
        assertEquals(30f, s.y0)
        assertEquals(40f, s.xc)
        assertEquals(50f, s.yc)
        assertEquals(60f, s.x1)
        assertEquals(70f, s.y1)
        assertEquals(8f, s.strokeWidth)
        assertEquals(100, s.r)
        assertEquals(150, s.g)
        assertEquals(200, s.b)
        assertEquals(120, s.a)
    }
}
