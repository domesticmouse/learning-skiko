Part 10 • Expressiveness & Graphics

Diverse Vector Primitives & Texture Shaders

Expand your painter's artistic vocabulary by implementing cubic Bézier splines, pressure-tapered calligraphy paths, low-poly convex polygons, and Skia gradient shaders.

1 Beyond Uniform Quadratic Arcs

In Lesson 2, our entire genome consisted of quadratic Bézier strokes with constant stroke width. While effective for simple curves, a quadratic curve can never change curvature direction (it cannot form an "S-curve").

To model realistic watercolor washes, calligraphic brush flourishes, and sharp geometric facets, we must empower our evolutionary engine with a polymorphic palette of vector primitives.

2 Cubic Béziers & Inflection Points

A cubic Bézier curve is defined by four points: start point \(P_0\), two control handles \(P_1\) and \(P_2\), and end point \(P_3\):

\[ B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t) t^2 P_2 + t^3 P_3, \quad t \in [0, 1] \]

Because it has two independent control points, a single cubic spline can bend into serpentines, wave crests, and sharp loops, allowing a single gene to represent complex organic forms such as eyelashes, hair strands, and flowing garments.

3 Pressure-Tapered Calligraphy Strokes

Real artist brushes do not maintain a robotic, uniform cylinder of paint. When an artist touches the canvas, the stroke begins with a delicate point, broadens under pressure, and tapers off as the brush lifts:

\[ w(t) = w_{start} \cdot (1-t) + w_{peak} \cdot 4t(1-t) + w_{end} \cdot t \]

In Skia, we can render pressure-tapered paths either by evaluating normal vectors along the spine to construct a filled closed Path polygon, or by stroking overlapping path segments with graduated strokeWidth values.

4 Translucent Convex Polygons

Instead of curved lines, a chromosome can be composed of translucent convex polygons (typically 3 to 6 vertices). Evolving 50 to 100 semi-transparent triangles creates stunning low-poly or cubist artworks reminiscent of early vector experiments.

In Skia, rendering a polygon is lightning-fast:

Skia Polygon Snippet
val path = Path().apply {
    moveTo(vertices[0].x, vertices[0].y)
    for (i in 1 until vertices.size) {
        lineTo(vertices[i].x, vertices[i].y)
    }
    closePath()
}
canvas.drawPath(path, fillPaint)

5 Skia Gradient Shaders

Skiko provides direct hardware-accelerated access to native Skia shaders via Shader.makeLinearGradient and Shader.makeRadialGradient:

Skia Linear Gradient Shader
val shader = Shader.makeLinearGradient(
    x0 = x1, y0 = y1, x1 = x2, y1 = y2,
    colors = intArrayOf(colorStart, colorEnd),
    positions = floatArrayOf(0.0f, 1.0f)
)
val paint = Paint().apply {
    this.shader = shader
    this.strokeWidth = width
    this.style = PaintMode.STROKE
}

When applied to brush strokes, gradient shaders emulate natural paint mixing, where a brush loaded with yellow on one edge and blue on the other creates an organic transition along its trajectory.

7 Polymorphic Gene Architecture in Kotlin

To combine diverse primitives in a single painting, define a sealed interface Gene in Kotlin:

Gene.kt 
import org.jetbrains.skia.Canvas
import org.jetbrains.skia.Paint

sealed interface Gene {
    fun render(canvas: Canvas)
    fun mutate(canvasWidth: Int, canvasHeight: Int): Gene
}

data class CubicCurveGene(
    val x0: Float, val y0: Float,
    val cx1: Float, val cy1: Float,
    val cx2: Float, val cy2: Float,
    val x3: Float, val y3: Float,
    val strokeWidth: Float,
    val argb: Int
) : Gene {
    override fun render(canvas: Canvas) {
        val path = org.jetbrains.skia.Path().apply {
            moveTo(x0, y0)
            cubicTo(cx1, cy1, cx2, cy2, x3, y3)
        }
        val paint = Paint().apply {
            color = argb
            strokeWidth = this@CubicCurveGene.strokeWidth
            mode = org.jetbrains.skia.PaintMode.STROKE
            isAntiAlias = true
        }
        canvas.drawPath(path, paint)
    }

    override fun mutate(canvasWidth: Int, canvasHeight: Int): Gene {
        // Stochastic perturbation of control handles...
        return copy(cx1 = cx1 + (Math.random().toFloat() - 0.5f) * 15f)
    }
}

data class PolygonGene(
    val points: List<Pair<Float, Float>>,
    val argb: Int
) : Gene {
    override fun render(canvas: Canvas) {
        val path = org.jetbrains.skia.Path().apply {
            moveTo(points[0].first, points[0].second)
            for (i in 1 until points.size) {
                lineTo(points[i].first, points[i].second)
            }
            closePath()
        }
        val paint = Paint().apply {
            color = argb
            mode = org.jetbrains.skia.PaintMode.FILL
            isAntiAlias = true
        }
        canvas.drawPath(path, paint)
    }

    override fun mutate(canvasWidth: Int, canvasHeight: Int): Gene {
        // Perturb vertex coordinates...
        return this
    }
}
