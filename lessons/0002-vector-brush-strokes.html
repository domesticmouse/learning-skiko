Part 2 • Genetic Representation

Vector Brush Strokes & Genotype Representation

Learn how to model visual artwork as digital DNA in Kotlin, render smooth curved brush strokes using Skiko's 2D vector path APIs, and design stochastic mutation operators.

1 Genotype vs. Phenotype in Genetic Art

In biological evolution, an organism's genotype is its genetic code (DNA sequence), while its phenotype is the physical organism expressed in the environment.

In procedural genetic art, we maintain the exact same distinction:

🧬 Genotype (The Code)

A compact data structure representing parameters: coordinates, curves, widths, colors, and opacity. In our codebase, this is modeled by StrokeGene and Painting.

🎨 Phenotype (The Image)

The 2D raster image resulting from executing drawing commands sequentially onto a Skia canvas. The fitness function evaluates the phenotype, not the genotype directly.

💡 Why Vector Primitives Over Raw Pixels?
If you mutated an array of 256×256 raw pixels independently, the search space would be \(256^{256 \times 256}\) — an astronomical impossibility to search. By compressing images into 100–150 vector brush strokes, we drastically reduce dimensionality while producing organic, painterly aesthetic results.

2 Quadratic Bézier Curves in Skia

Straight lines look mechanical. Natural brush strokes curve, bend, and trail off. In Skia, the most efficient curved stroke primitive is the Quadratic Bézier curve, defined by 3 points:

  • Start Point \((x_0, y_0)\): Where the brush touches down.
  • Control Point \((x_c, y_c)\): An off-curve attractor that pulls the curve toward it.
  • End Point \((x_1, y_1)\): Where the brush lifts off.

Mathematically, for \(t \in [0, 1]\), the curve point \(B(t)\) is:

\[ B(t) = (1 - t)^2 P_0 + 2(1 - t)t P_c + t^2 P_1 \]

In Skiko, drawing a quadratic Bézier curve requires two method calls on an org.jetbrains.skia.Path:

Kotlin (Skiko Path API) 
path.reset()
path.moveTo(x0, y0)
path.quadTo(xc, yc, x1, y1)
canvas.drawPath(path, paint)

3 The StrokeGene Class

Let's inspect StrokeGene.kt in your project. Each gene captures geometry, stroke width, and 32-bit RGBA color:

src/main/kotlin/StrokeGene.kt 
import org.jetbrains.skia.Canvas
import org.jetbrains.skia.Color
import org.jetbrains.skia.Paint
import org.jetbrains.skia.PaintMode
import org.jetbrains.skia.PaintStrokeCap
import org.jetbrains.skia.Path

data class StrokeGene(
    val x0: Float,
    val y0: Float,
    val xc: Float,
    val yc: Float,
    val x1: Float,
    val y1: Float,
    val strokeWidth: Float,
    val r: Int,
    val g: Int,
    val b: Int,
    val a: Int,
) {
    fun render(
        canvas: Canvas,
        paint: Paint,
        path: Path,
    ) {
        paint.color = Color.makeARGB(a, r, g, b)
        paint.strokeWidth = strokeWidth
        paint.mode = PaintMode.STROKE
        paint.strokeCap = PaintStrokeCap.ROUND
        paint.isAntiAlias = true

        path.reset()
        path.moveTo(x0, y0)
        path.quadTo(xc, yc, x1, y1)
        canvas.drawPath(path, paint)
    }
}
⚡ Performance Note: Buffer Reuse
Notice that render() accepts pre-allocated instances of Paint and Path rather than creating new ones inside each call. In genetic programming where thousands of evaluations occur per second, allocating temporary objects inside the render path triggers JVM Garbage Collection pauses. Reusing mutable buffers maintains 60+ FPS rendering and maximizes evolutionary throughput.

4 The Painting Chromosome

An individual artwork candidate is represented in Painting.kt as a list of strokes:

src/main/kotlin/Painting.kt 
data class Painting(
    val strokes: List,
    val error: Long = Long.MAX_VALUE,
) {
    fun render(
        canvas: Canvas,
        width: Float,
        height: Float,
        paint: Paint,
        path: Path,
        backgroundColor: Int = Color.WHITE,
    ) {
        // 1. Draw base coat
        paint.color = backgroundColor
        paint.mode = PaintMode.FILL
        canvas.drawRect(Rect.makeWH(width, height), paint)

        // 2. Draw brush strokes in sequential order
        for (stroke in strokes) {
            stroke.render(canvas, paint, path)
        }
    }
}

Order matters! Because strokes are rendered with alpha transparency (a < 255), overlapping strokes blend optically. Drawing stroke A before stroke B yields a different final pixel buffer than drawing stroke B before stroke A.

6 Stochastic Mutation Operators

How do we create variation without destroying established structure? Mutation happens at two hierarchical levels: chromosome-level (Painting.mutate()) and gene-level (StrokeGene.mutate()).

1. Chromosome-Level Mutation (Painting.kt)

When producing a child candidate, Painting.mutate() rolls a random float in \([0, 1)\) to choose between fine-tuning existing strokes, reordering paint layers, or replacing a dead-end stroke:

src/main/kotlin/Painting.kt 
fun mutate(
    width: Float,
    height: Float,
    rng: Random,
): Painting {
    if (strokes.isEmpty()) return this

    val roll = rng.nextFloat()
    val newStrokes = strokes.toMutableList()
    when {
        // 80% chance: Fine-tune 1 or 2 existing strokes
        roll < 0.80f -> {
            val count = if (rng.nextBoolean()) 1 else 2
            repeat(count) {
                val idx = rng.nextInt(newStrokes.size)
                newStrokes[idx] = newStrokes[idx].mutate(width, height, rng)
            }
        }
        // 15% chance: Swap z-order of two strokes (layering change)
        roll < 0.95f -> {
            val i = rng.nextInt(newStrokes.size)
            val j = rng.nextInt(newStrokes.size)
            Collections.swap(newStrokes, i, j)
        }
        // 5% chance: Replace a stroke completely with a fresh random stroke
        else -> {
            val idx = rng.nextInt(newStrokes.size)
            newStrokes[idx] = StrokeGene.random(width, height, rng)
        }
    }
    return copy(strokes = newStrokes, error = Long.MAX_VALUE)
}

2. Gene-Level Perturbation & Clamping (StrokeGene.kt)

Inside StrokeGene.mutate(), we pick one of five attributes to nudge slightly, using Kotlin's copy() and coerceIn() so strokes never drift off-canvas or overflow 8-bit color channels:

src/main/kotlin/StrokeGene.kt 
fun mutate(width: Float, height: Float, rng: Random): StrokeGene {
    return when (rng.nextInt(5)) {
        0 -> { // Jitter control point (xc or yc by ±12px)
            val delta = (rng.nextFloat() - 0.5f) * 24f
            if (rng.nextBoolean()) copy(xc = (xc + delta).coerceIn(0f, width))
            else copy(yc = (yc + delta).coerceIn(0f, height))
        }
        1 -> { // Jitter start or end point (±10px)
            val dx = (rng.nextFloat() - 0.5f) * 20f
            val dy = (rng.nextFloat() - 0.5f) * 20f
            if (rng.nextBoolean()) copy(x0 = (x0 + dx).coerceIn(0f, width), y0 = (y0 + dy).coerceIn(0f, height))
            else copy(x1 = (x1 + dx).coerceIn(0f, width), y1 = (y1 + dy).coerceIn(0f, height))
        }
        2 -> { // Nudge one RGB channel by -15..+15
            val delta = rng.nextInt(31) - 15
            when (rng.nextInt(3)) {
                0 -> copy(r = (r + delta).coerceIn(0, 255))
                1 -> copy(g = (g + delta).coerceIn(0, 255))
                else -> copy(b = (b + delta).coerceIn(0, 255))
            }
        }
        3 -> { // Nudge opacity (Alpha) within translucent bounds [20, 230]
            val delta = rng.nextInt(21) - 10
            copy(a = (a + delta).coerceIn(20, 230))
        }
        else -> { // Nudge stroke thickness within [2px, 35px]
            val delta = (rng.nextFloat() - 0.5f) * 4f
            copy(strokeWidth = (strokeWidth + delta).coerceIn(2f, 35f))
        }
    }
}
💡 Why Mutate One Attribute at a Time?
If you mutated position, color, and thickness simultaneously on every step, a beneficial color tweak would frequently be rejected because it was paired with a destructive coordinate jump. Isolating mutations to 1–2 parameters per step lets the hill climber credit individual improvements cleanly.

7 Automated Testing & Verification

To ensure mutations maintain valid geometric bounds, color ranges, and proper chromosome copying semantics, we write comprehensive unit tests using kotlin.test.

src/test/kotlin/VectorBrushTest.kt 
import org.jetbrains.skia.Paint
import org.jetbrains.skia.Path
import org.jetbrains.skia.Surface
import kotlin.random.Random
import kotlin.test.Test
import kotlin.test.assertEquals
import kotlin.test.assertNotEquals
import kotlin.test.assertTrue

class VectorBrushTest {
    private val rng = Random(12345)
    private val width = 400f
    private val height = 300f

    @Test
    fun testStrokeGeneCreationAndBounds() {
        val stroke = StrokeGene.random(width, height, rng)
        assertTrue(stroke.x0 in 0f..width, "x0 must be within width")
        assertTrue(stroke.y0 in 0f..height, "y0 must be within height")
        assertTrue(stroke.strokeWidth in 3f..25f, "strokeWidth in [3, 25]")
        assertTrue(stroke.r in 0..255 && stroke.g in 0..255 && stroke.b in 0..255)
        assertTrue(stroke.a in 30..180, "alpha in [30, 180]")
    }

    @Test
    fun testStrokeGeneMutationStaysWithinBounds() {
        var stroke = StrokeGene.random(width, height, rng)
        for (i in 0 until 500) {
            stroke = stroke.mutate(width, height, rng)
            assertTrue(stroke.x0 in 0f..width && stroke.y0 in 0f..height)
            assertTrue(stroke.xc in 0f..width && stroke.yc in 0f..height)
            assertTrue(stroke.x1 in 0f..width && stroke.y1 in 0f..height)
            assertTrue(stroke.strokeWidth in 2f..35f)
            assertTrue(stroke.r in 0..255 && stroke.g in 0..255 && stroke.b in 0..255)
            assertTrue(stroke.a in 20..230)
        }
    }

    @Test
    fun testPaintingCreationAndMutation() {
        val strokeCount = 40
        val painting = Painting.createRandom(strokeCount, width, height, rng)
        assertEquals(strokeCount, painting.strokes.size)

        val mutated = painting.mutate(width, height, rng)
        assertEquals(strokeCount, mutated.strokes.size)
        assertEquals(Long.MAX_VALUE, mutated.error, "Mutated child should have error reset to MAX_VALUE")
        assertNotEquals(painting.strokes, mutated.strokes, "Mutated painting strokes should differ")
    }

    @Test
    fun testPaintingRenderOntoSurface() {
        val surface = Surface.makeRasterN32Premul(width.toInt(), height.toInt())
        val canvas = surface.canvas
        val paint = Paint()
        val path = Path()

        val painting = Painting.createRandom(25, width, height, rng)
        painting.render(canvas, width, height, paint, path)

        assertEquals(width.toInt(), surface.width)
        assertEquals(height.toInt(), surface.height)
    }
}
