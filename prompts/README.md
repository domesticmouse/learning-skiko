## Project Overview

The project evolved across 13 distinct milestone conversations:
1. **Environment & Setup**: Validated macOS OpenJDK 21, Gradle, and Skiko dependencies.
2. **Desktop App Foundations**: Built a Skiko desktop app, added Ktlint, and created custom skills.
3. **Genetic Programming**: Implemented the (1+1) Hill Climber evolutionary loop for vector brush strokes.
4. **Immutability & Data Classes**: Converted mutable data classes to immutable copies and resolved macOS Java symlinks.
5. **Interactive Curriculum**: Authored lessons 0001 through 0005 with interactive quiz widgets and styles.
6. **Math Formatting**: Added KaTeX formula rendering to all HTML lessons.
7. **Extension Roadmap**: Planned advanced modules (island models, perceptual fitness, parsimony, SVG export).
8. **Extension Lessons**: Authored lessons 0006 through 0011.
9. **Pedagogical Review**: Audited all lessons and migrated color fitness to Euclidean L2 distance.
10. **Runnable Steps**: Created isolated step projects in `steps/` for every lesson and cleaned up root clutter.
11. **GitHub Publishing**: Created the root README for `domesticmouse/learning-skiko`.
12. **GitHub Pages & CI/CD**: Deployed GitHub Actions workflow, navigation index, and fixed deployment permissions.
13. **Prompt Archival**: Explored session traces and archived conversation prompt records.
