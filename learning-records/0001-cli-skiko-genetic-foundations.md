# Established CLI Skiko & Genetic Art Learning Track

The user established a learning track to master Kotlin desktop graphics (Skiko) and genetic programming by deconstructing an existing evolutionary brush-stroke painter app into incremental build stages. All learning is bounded by a pure command-line workflow (Gradle CLI, `./gradlew run`, Ktlint) with no IDE dependency, setting the initial floor for hands-on exercises and lesson pacing.
