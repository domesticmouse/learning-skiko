Learning Skiko & Genetic Art

A hands-on, command-line-first curriculum and reference implementation for mastering hardware-accelerated 2D graphics in Kotlin using Skiko (JetBrains' Skia bindings for Kotlin Multiplatform) and evolutionary algorithms.

Kotlin 2.1.0 Skiko 0.8.18 JDK 21 LTS Command Line First Hardware Accelerated

✦ Course Architecture & Philosophy

This series guides you step by step from an empty directory to a multi-core evolutionary art generator that reconstructs target images with thousands of procedural vector brush strokes:

⚡ Pure Skiko & Terminal Workflow

No heavy IDEs or bloated UI toolkits. Every lesson builds and executes cleanly via standard Gradle CLI commands with native macOS, Linux, and Windows runtime resolution.

🧬 Zero-Allocation Engine

Evaluate thousands of image candidates per second using direct headless Skia raster buffers, branchless squared-difference loops, and immutable chromosome models.

🏝️ Parallel Island Concurrency

Scale evolutionary pressure across all CPU cores with isolated worker demes, lock-free atomic synchronizers, and asynchronous ring migration.

🚀 Command-Line Quickstart

Every lesson corresponds to a standalone runnable Gradle project under the steps/ directory. You can run any lesson code directly from your terminal:

# Navigate to step 1 (Basic Skiko desktop window) cd steps/0001-skiko-desktop-foundations ./gradlew run # Navigate to step 5 (Real-time genetic painter) cd ../0005-realtime-visualization-hud ./gradlew run # Check Kotlin code formatting and linting ./gradlew ktlintCheck
